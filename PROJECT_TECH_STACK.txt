================================================================================
AR MOBILE TEARDOWN SYSTEM - TECH STACK & QUICK EXPLANATION GUIDE
================================================================================

1. PROJECT OVERVIEW (10-Second Summary)
--------------------------------------------------------------------------------
An Augmented Reality (AR) web application that detects a physical smartphone 
through the camera, analyzes its hardware signatures, and projects an interactive 
3D exploded teardown view with touchless AI hand-gesture controls.


2. CORE TECH STACK BREAKDOWN
--------------------------------------------------------------------------------

A. FRONTEND & CORE FRAMEWORK:
   * React 18 (SPA - Single Page Application)
   * Vite 5 (Ultra-fast Next-Gen Build Tool & Dev Server)
   * Tailwind CSS 3 (Futuristic Cyberpunk Glassmorphism UI & HUD)
   * React Router DOM v6 (Routing between Home, App, Specs, and Docs)
   * Lucide React (Clean, modern iconography)

B. 3D GRAPHICS & AUGMENTED REALITY (AR):
   * Three.js (WebGL 3D engine for procedural smartphone 3D models)
   * React Three Fiber (@react-three/fiber - React wrapper for Three.js)
   * React Three Drei (@react-three/drei - 3D helpers, lighting, camera controls)
   * Raycasting (3D mouse/finger ray-intersection for component inspection)

C. ARTIFICIAL INTELLIGENCE & COMPUTER VISION:
   * TensorFlow.js (@tensorflow/tfjs) (In-browser neural network execution)
   * COCO-SSD Model (Real-time smartphone detection & bounding box tracking)
   * Custom Visual Signature Classifier (HSV Hue, RGB Euclidean distance, 
     aspect ratio, and camera layout analysis)
   * Tesseract.js (Client-side optical character recognition fallback)

D. HAND TRACKING & GESTURE ENGINE (Touchless AR Control):
   * Google MediaPipe Vision (@mediapipe/tasks-vision)
     - 21 3D hand landmarks tracking at 90 FPS
   * Custom HandGestureEngine (Zero-latency vector math):
     - 2-Finger Touch & Open: Disassemble / Explode components
     - Palm Close / Fist: Assemble phone back together
     - 2 Fingers Crossed/Extended Move: Free 3D rotation (90 FPS)
     - 2 Fingers Joined over part: Real-time component spec inspection

E. ANIMATION & LOCALIZATION:
   * GSAP (GreenSock Animation Platform) - Smooth exploded-view transitions
   * Framer Motion - Fluid UI deck animations
   * i18next & react-i18next - Multi-language support (English, Tamil)

F. CLOUD DEPLOYMENT & CI/CD:
   * GitHub (Version Control & collaboration)
   * Vercel (Edge serverless deployment with automated CI/CD)


3. HOW THE ARCHITECTURE WORKS (Flow of the App)
--------------------------------------------------------------------------------
Step 1: Camera Stream
        User opens the app; browser requests camera access via WebRTC getUserMedia.

Step 2: Object Detection (COCO-SSD)
        TensorFlow.js scans video frames at 4 FPS to identify physical smartphones 
        and extracts a normalized bounding box with exponential smoothing.

Step 3: Visual Hardware Analysis (< 50ms)
        Cropped phone canvas is analyzed for chromatic color, aspect ratio, 
        and brand signatures. Shows 50% accurate estimate on reticle with 3 
        camera-analyzed suggestions.

Step 4: 3D AR Teardown Projection
        Once confirmed, procedural 3D phone model renders aligned over camera feed 
        with all internal layers (Display, Motherboard, Battery, Cameras, etc.).

Step 5: Hand Gesture Tracking (MediaPipe)
        MediaPipe tracks 21 hand landmarks in real-time without re-rendering React, 
        allowing direct 3D manipulation with zero lag.
